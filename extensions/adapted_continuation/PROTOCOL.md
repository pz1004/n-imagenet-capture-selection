# Chronological follow-up after adaptation

This retrospective experiment uses the 36,000 evaluation photographs already studied. The primary estimand is the mean of five adapted Histogram policies’ horizontal-switch minus same-recording vertical-continuation differences in cohort top-1 accuracy. Each state starts from the first 30,000 transfer vertical events (or shorter record). A shared gate across follow-up arms requests when first confidence is below the 30th percentile (higher quantile) of that state’s 4,500 policy-calibration sources. Those sources are disjoint from the 4,500 unlabeled adaptation images, with five of each per class. Reuse archived trajectory-specific BN parameters from the five existing Ev-TTA fits. Refit released policies at the identical 4,500-source calibration budget.

On a request compare a second vertical block (events 30,001–60,000 in the same recording), a separately recorded 30,000-event horizontal prefix, and the training-matched square prefix as a secondary control. Each uses the existing penalized logistic selector fitted on eligible, discordant calibration images only. Incomplete follow-ups retain the first class and count toward workload. Report full-cohort accuracy, requested/complete counts, attainable rescues, realized rescues and losses, seed estimates/range, and adapted-minus-released interaction. Check the common released-state request mask, all-trajectory complete-source subset with the original gate, and a quota of 10,800. Hold source draws across all arms and seeds paired. Refit numerical cutoffs and terminal selectors in 2,000 within-class and 2,000 whole-class bootstrap draws; the latter use the same class multiplicities in independently held calibration and test sources. Uncertainty conditions on the five frozen states. Summarize previously measured scan orders by paired request-mask strata as a separate descriptive analysis. No new training, chronological square/linear path reoptimization, or upstream event acquisition.

Runtime scripts verify pinned raw archives, source/label correspondence, state provenance and calibration parity. Save the logits and per-source decisions. This protocol is recorded locally before deriving new scores.
