# Candidate-accuracy diagnostic

This retrospective diagnostic expands the planned comparison of standalone and requested-policy rankings. Its symmetric contrasts were requested after interim horizontal-versus-continuation policy point estimates became available. It leaves the original primary comparison and freeze receipt intact. On common complete sources, calculate the accuracy of each candidate used alone and the corresponding calibrated policy accuracy. Across all sources, direct use of a candidate falls back to the first result when the candidate window is incomplete. Estimate released and five-state mean pairwise differences for horizontal versus continued vertical, square versus continued vertical and square versus horizontal. Report paired bootstrap intervals using the same multiplicities and calibration refits as the primary estimates. Each state is evaluated on the same sources, including in contrasts between the five-state mean and the released classifier. Report weak or opposite individual-seed effects descriptively. The primary tests were specified in PROTOCOL.md.
